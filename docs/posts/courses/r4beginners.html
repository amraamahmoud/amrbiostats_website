Getting Started with R

مزايا استخدام R و توضيح الفرق بين R و RStudio.

Downloading and Installing R and RStudio

تحميل وتثبيت R و RStudio لنظامي التشغيل macOS و Windows.

RStudio Interface

التعرف علي واجهة برنامج RStudio وكيفية التعامل مع الوظائف المختلفة.

RStudio Projects

إنشاء Projects جديدة والتعامل مع الملفات والمجلدات.

R Packages

التعرف علي أنواع Packages، المصادر المختلفة لتثبيتها، وكيفية استخدامها.

R Fundamentals

استخدام R لتنفيذ Mathmetical operations، التعامل مع Relational operators، توضيح الفرق بين Scientific and Exponential notations، والتعرف علي Special values في R.

R Objects

التعرف علي R objects، كيفية إنشائها باستخدام Assignment operators، التعامل مع Environment pane، والتعرف علي Object naming rules.

Data Types & Atomic Vectors I

إنشاء Vectors، الأنواع الأساسية، الخصائص، وأنواع Coercion.

Atomic Vectors II

تنفيذ Arithmetic operations، التعرف علي مفهوم Vectorization و Vector recycling، و Vector comparison, subsetting, and subassignment.

R Functions

استخدام Functions والتحكم في Arguments و كتابة واستخدام Custom functions بسيطة.

Matrices and Arrays

إنشاء المصفوفات و أنواعها، تنفيذ Arithmetic opertions علي المصفوفات، عمل Subsetting للمصفوفات، و Arrays.

Lists & Data Frames

إنشاء Lists و Data frames و عمل Subsetting لهم.

Working with Data in R

استيراد ملفات البيانات المختلفة، فحص البيانات، تنظيمها، وصف بسيط للبيانات، و عمل Base R plots.

Beyond R Basics

مقدمة قصيرة عن استخدام ggplot2 لعمل الرسومات المتقدمة، إنشاء جداول صالحة للنشر، استخدام Quarto لعمل التقارير، وطرق استخدام AI بمسؤولية داخل RStudio.
